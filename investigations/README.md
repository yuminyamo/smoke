# investigations

手順書の運用中に起きた事象を、発生環境で調査するための調査票を置く。

- 1事象につき1ファイル。ファイル名は `<連番3桁>_<事象の要約>.md`
- 調査票には、調査の目的・調査する側の制約・確認事項・回答欄を書く
- 発生環境のAIは、調査票の回答欄に直接記入して返す。返ってきたものを同じファイルに上書きして残す
